# Restaurant Management System

A web-based Restaurant Management System developed using Python, Flask, and MySQL to streamline restaurant operations. The system provides features for managing menu items, customer orders, table reservations, payments, and order status tracking through a user-friendly interface.

### Key Features
- **Admin Dashboard:** Manage restaurant operations and menu items.
- **Menu Management:** Add, update, and manage food items, prices, categories, and availability.
- **Order Management:** Place orders and track their status.
- **Table Reservations:** Manage customer table bookings.
- **Payment Management:** Support different payment methods and maintain payment records.
- **Database Integration:** Store and manage restaurant data using MySQL.
- **Responsive Interface:** Provide an intuitive interface for users.

### Technologies Used
- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
- **Tools:** VS Code, MySQL Workbench, Git, GitHub

This project demonstrates the practical implementation of web development, database management, and CRUD operations in a restaurant environment.
